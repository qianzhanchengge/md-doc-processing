# 校验与回归检查

原则：**每个处理都要有量化校验**。本文件列出全部检查项、实现要点与"历史反例库"
（这些坑都真实发生过，作为新任务的回归基线）。

---

## 1. 机器校验（verify_output.mjs）

### 1.1 代码容器数量对账（最强的一把尺）★

```
raw HTML 中 (<pre …> 数 + <div class="example_code"> 数)  ==  md 中围栏代码块数
```

逐文件比对，**差值必须为 0**。这一项能一眼抓出"某一类代码容器漏处理"（历史反例：
166 个 `example_code` 被当普通文本转义，普通检查全过、只有对账抓到）。

### 1.2 围栏配对（CommonMark 规则，不要简单数奇偶）

- 先剥掉引用块前缀：`^(\s*>+\s*)+`（引用块里的围栏合法）；
- 闭合围栏要求：同样字符、长度 ≥ 开启长度、**行内不能有 info string**；
- 围栏内的 ` ```python `（带 info）**不是**闭合行，是内容；
- 若有未闭合围栏 → 文件级报错。

### 1.3 回归检查（历史 bug 特征）

| 检查 | 判据 | 防什么 |
|---|---|---|
| 代码块空行占比 | 块内空行 > 3 且空行 ≥ 非空行 × 0.9 → 报警 | "每行代码后多一个空行"（`<br>` 旁格式换行符未丢弃） |
| 块外残留转义 | 块外 `\#` `\.` `\_` `\[` 等行数 ≥ 20 → 报警 | 整段内容被当文本转义（代码块漏识别） |
| 硬换行汤 | 块外尾随双空格行 > 100 → 报警 | 文本块整体被硬换行拍平 |

### 1.4 内容残留

- HTML 标签残留（块外正则 `<div|span|…>`）；
- HTML 实体残留（`&nbsp;` `&amp;` `&#123;` 等）；
- `example_code` 等容器类名残留；
- 每个文件应以 `# ` 标题开头。

### 1.5 图片完整性

- md 中每个 `![](images/…)` 引用的文件**存在**；
- `images/` 目录**无孤儿**（未被任何 md 引用）；
- 抽样校验文件头（magic bytes）与扩展名一致（png/jpg/gif/webp/svg）。

### 1.6 可选：文本量对照

`contentLen`（原始正文 HTML 长度）与 md 字符数留档，人工扫一眼有无"大页面产出极小文件"
的异常（通常是整段内容丢失）。

## 2. 人工渲染验证（机器测不出"显示是否正确"）

| 对象 | 方法 |
|---|---|
| 内联 SVG | `agent-browser tab new "file:///…/x.svg"` 截图，与线上页面同图比对（颜色/文字/连线） |
| 录制的 GIF | `ffmpeg -i out.gif -vf "select=eq(n\,60)" -frames:v 1 mid.png` 抽中间帧查看；再抽首/尾帧确认循环 |
| 公式 | md 里的 `$$…$$` 行肉眼确认为合法 LaTeX（单反斜杠、真下标） |
| 动画组件区域 | 录制帧与"实时页面截图"做像素比对，确认无录制伪影；页面自身特性（如主题 CSS 撞车产生的元素）**忠实保留** |

## 3. 抽样通读

- 每类特殊格式抽 1 章读原文；
- 随机抽 2~3 个普通章节通读（防串行/缺段/乱码）；
- 打开任意 2~3 个 md 的"首图/首表/首代码块"区域——这三个位置最常见格式问题。

## 4. 历史反例库（回归基线）

1. **只处理一种代码容器** → 另一类（SyntaxHighlighter 风格）整段被转义成 `\#` `\=` 乱码。
   → 教训：先全站扫描容器种类，处理后用"数量对账"验收。
2. **`<br>` 旁格式换行符** → 每行代码后多一个空行（截图里整段代码"被拉伸"）。
   → 教训：`<br>` 与文本节点相邻时丢弃纯格式换行。
3. **围栏不配对** → 代码含 ` ``` ` 时外层围栏被提前闭合，后续正文被吞进代码块。
   → 教训：外层围栏 = 内容最长反引号串 +1。
4. **独立 SVG 变黑块** → 内联 svg 的颜色在页面 CSS 类/CSS 变量里，抽取时未内嵌。
   → 教训：SVG 抽取必须"内嵌 class 规则 + 解析 var()"；用 file:// 渲染比对验收。
5. **公式乱码** → MathML + katex-html + x-tex 注解三者都在页面里，拍平后三种表示混杂。
   → 教训：只取注解 LaTeX，其余整体替换；注解是双重转义（`\\_`→`_`）。
6. **知识库搜不到标识符** → turndown 过度转义（`SECRET\_KEY`）。
   → 教训：块外定向反转义；但行首 `1\.` 与 `\\.`(转义的反斜杠) 必须保留。
7. **动图被拍平成文字** → JS 驱动的动画组件被当普通 DOM 转文本。
   → 教训：先按"连续动画 / 一次性入场动画"分类，分别录 GIF / 截图；
   组件替换必须放在通用 img 处理器**之后**，避免下载器误处理本地路径。
